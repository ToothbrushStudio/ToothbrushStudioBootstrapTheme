# CLAUDE.md

## Scope of this package

This repo owns Bootstrap **token overrides** (`_variables.scss`) and a **short, named list** of
signature after-Bootstrap component overrides (`_components.scss`) — not a full component
library. The Mouth menu, teeth, brush animation, and other Toothbrush Studio website-specific UI
live in the `ToothbrushStudioWebsite` repo, not here. Reusable, buyer-facing widgets belong to the
future **Chomponents** product, also not here. When in doubt: "does a generic Bootstrap-theme
adopter want this in their bundle?" — if no, it doesn't belong in this package.
